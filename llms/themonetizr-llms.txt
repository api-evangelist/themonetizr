# Monetizr (TheMonetizr)

> Monetizr is a gaming media platform for in-game brand advertising. It turns gameplay into
> measurable, voluntary brand engagement through branded campaigns and missions rewarded in-game.
> The Monetizr Campaigns API (base https://api.themonetizr.com) serves active campaigns to games
> and is consumed by the official Unity SDK; authentication is a per-game HTTP Bearer API key.

## APIs
- [Monetizr Campaigns API](https://api.themonetizr.com): List branded campaigns/missions, reset progress, and claim rewards for a game.

## Operations (derived from the official Unity SDK)
- GET /settings — global settings dictionary that configures campaign/SDK behavior
- GET /api/campaigns — list active campaigns/missions for the game
- GET /api/campaigns/{campaignId}/reset — reset a campaign's state for the player
- POST /api/campaigns/{campaignId}/claim — claim the reward for a completed campaign
